# YOLOE-26's text-prompt path (detect_by_text -> YOLOE.set_classes ->
# get_text_pe) needs a CLIP text encoder that its visual-prompt path
# (detect_by_exemplar) doesn't. Without this pinned here, ultralytics
# silently `pip install`s this same package via its own "AutoUpdate" at
# first text-prompt call instead — a runtime network fetch that breaks the
# "nothing is fetched at runtime" offline-deployment invariant (see
# model_servers/README.md §8). Installing it at build time here means the
# image already has it baked in — verified this is the exact package
# ultralytics reaches for by observing its own AutoUpdate output.
